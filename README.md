# skills

Agent skills by Rhys Sullivan.

## Install

```bash
npx skills add RhysSullivan/skills
```

Or install a single skill:

```bash
npx skills add RhysSullivan/skills --skill quality-code
```

## Skills

- **[no-ui-flash](skills/no-ui-flash/SKILL.md)** — stop apps flashing the wrong UI before client data resolves (skeleton-then-login, skeleton-then-empty-state, theme flash): resolve the state at the edge, seed correct paints from a hint cookie, and test the loading window by holding the probe open.
- **[quality-code](skills/quality-code/SKILL.md)** — principles for writing quality full-stack TypeScript: branded types, discriminated unions, end-to-end types, real tests over mocks, OpenTelemetry, picking the right abstractions.
- **[how-to-earn-a-billion-dollars](skills/how-to-earn-a-billion-dollars/SKILL.md)** — generate and evaluate startup ideas with Paul Graham's framework: outcome = growth rate × duration, growth from users loving the product enough to tell friends (empathy, not exploitation), and finding ideas by building cool things with friends. Adapted from his essay "How to Earn a Billion Dollars."
- **[write-better-error-messages](skills/write-better-error-messages/SKILL.md)** — review and rewrite product error messages so users understand what happened, what was preserved, and what to do next. Adapted from Jenni Nadler's Wix UX article "When life gives you lemons, write better error messages."
